【m10 光伏运行效率监测｜使用说明】

程序版本：开发中（以 README 和 evidence 记录为准）
数据说明：项目内 pv_demo.csv 是固定种子合成演示数据，仅用于流程验证，不代表真实场站测量。
目标环境：Windows 10/11 x64；Windows 原生构建和验收当前尚未完成。

一、启动
1. 将整个文件夹完整解压到普通可写目录，路径可包含空格和中文。
2. 双击 start.cmd。
3. 启动成功后浏览器访问 http://127.0.0.1:8000/。如果浏览器未自动打开，请手动输入该地址。
4. 如窗口提示“后端入口尚未构建”或依赖缺失，请保留窗口中的错误信息并查看 logs/；不要把启动失败当作服务已就绪。

二、演示流程
1. 打开“导入与运行”，选择 CSV，或勾选“使用项目内固定种子演示数据”。
2. 选择本地轻量模式，确认聚类数量和异常比例后点击“开始处理”。
3. 在“运行总览”查看记录数、异常数、告警数和工况分布。
4. 在“曲线分析”切换发电功率、辐照度和效率代理值。
5. 在“异常记录”按站点、时间和等级筛选，可导出当前结果。
6. 在“告警中心”查看需要复核的异常工况，在“运行记录”追溯处理参数。

三、关闭
双击 stop.cmd。它只停止本项目启动器记录的进程，不会关闭其他项目。

四、常见问题
- 双击窗口一闪而过：从命令行运行 start.cmd，查看显示的阶段和 logs/ 文件；不要删除数据目录。
- 浏览器无法连接：确认启动窗口没有报错，并检查 8000 端口是否被占用。
- CSV 导入失败：检查必需字段、时间格式、数值列和 UTF-8 编码；空文件和缺字段会被拒绝。
- 数据或日志无法写入：将整个项目移动到用户可写目录后重试。
- Docker/HDFS 不可用：使用“本地轻量模式”演示；页面不会伪装成已写入 HDFS。

五、限制
当前程序的 Windows x64 离线构建和长期并发能力仍需在对应环境中验证。PVDAQ 公开数据切片已完成本地与 Docker 集群联调，但不代表现场数据；论文不得把合成演示数据写成真实场站数据。
